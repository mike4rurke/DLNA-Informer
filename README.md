# Informer CYD + yoRadio

Реализация для ESP32-2432S028R (дисплей ILI9341 320×240) с шестью экранами
и управлением отдельным приёмником
[yoRadio_spdif](https://github.com/romekb/yoRadio_spdif). Проект создан
по мотивам [MultiInformer](https://github.com/altJSV/multiinformer),
но не является построчным портом исходной программы.

## Возможности

- NTP, календарь и погода OpenWeather для четырех городов; местное время каждого
  города рассчитывается по UTC-смещению из ответа OpenWeather. Погода
  показывается красивыми иконками: солнце, луна, переменная облачность,
  облака, дождь, снег, гроза и туман (по коду иконки OpenWeather).
- Будильник по дням недели с сохранением в NVS, таймер и визуальное оповещение.
  Для звука нужен динамик на штатном выходе CYD (усилитель на GPIO 26).
- При срабатывании будильник отправляет yoRadio команду старта. Таймер не
  управляет радио и не сохраняет отсчёт при отключении питания.
- Пульт yoRadio: предыдущая/следующая станция, старт/стоп, громкость, данные
  о станции и треке по WebSocket. Используются `/?start=1`, `/?toggle=1`,
  `/?prev=1`, `/?next=1`, `/?vol=N`, `/?play=N`, `/?mode=0/1` и `/ws`
  из указанного форка.
- Экран «Радио»: переключатель Радио/SD и список станций или SD-файлов.
  Списки читаются с приёмника: `/data/playlist.csv` (WEB) и
  `/data/playlistsd.csv` (SD, формат `Название<TAB>URL<TAB>0`). Тап по строке
  включает станцию командой `play=N`. Обновление — каждые 5 минут и по кнопке.
- Экран «Настройки»: яркость подсветки, звук CYD, IP и RSSI Wi-Fi, обновление
  данных, сброс калибровки тача и файловый менеджер SD-карты (папки, постраничный список и размеры, только чтение). SD делит шину VSPI с тачем: на время чтения
  шина переключается и возвращается обратно. Если карта не видится — нужна
  FAT32 (exFAT не поддерживается), монтирование повторяется на 4/2/1 МГц.
- Курсы валют остались: экран «Курсы» показывает индикативные курсы MOEX
  (USD/RUB, EUR/RUB, CNY/RUB, GBP/RUB, обновление каждые 30 минут).
  Если сеть или источник недоступны, вместо вымышленных значений
  отображается сообщение об ошибке.

## Телевизор LG LB65 (webOS)

LG 42LB650V относится к webOS, а не NetCast: прежний запрос ROAP на порту
8080 для этой модели не подходит. Управление переведено на webOS SSAP через
WebSocket `ws://IP:3000` (подходит старым моделям). В `include/config.h`
укажите актуальный `TV_HOST`. Включите телевизор, подключите его к той же сети
и разрешите LG Connect Apps, если эта настройка присутствует. На экране CYD
откройте «ТВ», подтвердите запрос подключения на телевизоре штатным пультом.
Это **подтверждение**, а не шестизначный код. Возвращённый клиентский ключ
сохраняется в NVS. Кнопка «Сопряжение» стирает его и запрашивает подтверждение
заново. `TV_PAIR_KEY` больше не используется. Для выключенного ТВ включение
по сети не реализовано. Совместимость других LG, включая NetCast и современные
модели с обязательным TLS, не заявляется.

## Сборка и прошивка

1. Установите [PlatformIO IDE](https://platformio.org/install/ide?install=vscode).
2. Откройте папку `firmware` как проект PlatformIO.
3. Задайте в `include/config.h` Wi-Fi 2.4 ГГц, ключ OpenWeather, города и
   IP/порт вашего yoRadio. Значения в этом файле по умолчанию пустые.
4. Подключите CYD USB-кабелем с передачей данных и выберите его COM-порт.
5. Соберите и прошейте окружение `cyd-ili9341`:

   ```sh
   pio run -e cyd-ili9341 -t upload
   ```

   При необходимости добавьте `--upload-port COM3` или `/dev/ttyUSB0`.
   `uploadfs` не требуется. Готовый бинарный файл находится в
   `.pio/build/cyd-ili9341/firmware.bin`.
6. При первом включении нажмите две жёлтые метки для калибровки тача. Чтобы
   повторить калибровку, удерживайте BOOT при перезагрузке платы.

Архив, сформированный веб-конфигуратором, содержит эти же исходники с вашим
`config.h`. Сам архив не является готовым бинарным файлом прошивки.

## Дисплей

Только ILI9341, портрет 240×320 (`ILI9341_2_DRIVER`, поворот 0). Типовая распиновка
CYD: TFT MOSI 13, MISO 12, SCK 14, CS 15, DC 2, подсветка 21;
XPT2046 MOSI 32, MISO 39, SCK 25, CS 33, IRQ 36.
Экран и тач используют разные SPI-шины.

Погода и MOEX используют HTTPS с `setInsecure()`: шифрование включено, но
сертификат сервера не проверяется. Используйте доверенную сеть. Команды
yoRadio отправляются по HTTP и WebSocket без шифрования. Не публикуйте
`include/config.h` и собранный бинарник, если они содержат пароли или ключи.

Шрифты сгенерированы из DejaVu Sans; условия находятся в
`docs/DEJAVU-LICENSE.txt`.

Протокол управления и формат WebSocket сверены с исходниками
[yoRadio_spdif, commit b96a01d](https://github.com/romekb/yoRadio_spdif/tree/b96a01d).
В других версиях форка совместимость необходимо проверить отдельно.

## SD: файловый менеджер и веб-интерфейс

В «Настройки» прокрутите вниз до списка SD. Касание папки открывает её;
«Вверх» возвращает к родительской папке, стрелки переключают страницы по 12
элементов. Длинные имена папок, не помещающиеся во внутренний буфер, можно
открыть через веб-интерфейс. Список выводится в порядке файловой системы.

Откройте `http://IP-CYD/` с устройства в той же сети; IP указан в настройках
на экране CYD. Веб-интерфейс работает с картой **самого CYD**, а не yoRadio.
Для скачивания нажмите название файла. Переход по папкам доступен по ссылкам.

Для загрузки и удаления сначала задайте в `include/config.h` непустые
`SD_WEB_USER` и `SD_WEB_PASSWORD`, затем соберите и прошейте устройство.
В браузере войдите с этими данными. Кнопка «Удалить» удаляет файл, но не
папку; для загрузки откройте нужную папку и выберите файл. Имеющийся файл не
перезаписывается: сначала удалите его вручную. При сбое загрузки временный
файл удаляется по возможности; после внезапного отключения питания может
остаться скрытый `.cyd-*.tmp`. При пустом пароле запись отключена, но просмотр
и скачивание не защищены.

Авторизация работает по HTTP Basic **без шифрования**: пароль и данные видны
в сети. Доступ к UPnP/DLNA для медиаклиентов остаётся без пароля независимо от
настроек веб-интерфейса. Не пробрасывайте порт в интернет, используйте только
доверенную сеть. Во время загрузки/скачивания крупного файла экран, тач,
таймер и будильник могут временно не обновляться. SD-файловые операции
выполняются последовательно. Папки в веб-интерфейсе не удаляются и не создаются.

Карта FAT32; типовые GPIO SD: CS 5, CLK 18, MISO 19, MOSI 23. SD и тач
используют один контроллер SPI с разными выводами; между обращениями шина
останавливается и перенастраивается. Фактическая распиновка зависит от ревизии
платы.

## Проверка

Проект собран PlatformIO для `cyd-ili9341`. На физическом CYD и телевизоре
эта версия не проверялась. Для сопряжения см. раздел «Телевизор LG LB65 (webOS)» выше.

## Музыка SD по UPnP/DLNA

CYD объявляет медиаисточник `CYD SD Music` в локальной сети по SSDP. На
совместимом проигрывателе откройте сетевые источники / UPnP / DLNA и выберите
этот сервер, папку и файл. Это сервер источника, а не функция принудительной
отправки на произвольный проигрыватель: выбор и запуск осуществляет клиент.
Карта должна находиться в самом CYD. Каталоги и файлы MP3, FLAC, WAV, M4A,
AAC и OGG видны в списке; воспроизведение зависит от поддержки формата
проигрывателем. Реализован базовый UPnP MediaServer с Browse, а не полная
DLNA-сертификация; отдельные приложения могут оказаться несовместимы.

Только одна операция SD обрабатывается за раз. Пока проигрыватель считывает
аудиофайл, интерфейс CYD и обработка будильника/таймера могут зависнуть до
завершения передачи. Не используйте их как критически важные во время
воспроизведения. Доступ к медиатеке не защищён паролем, HTTP не зашифрован;
используйте доверенную локальную сеть без изоляции клиентов и не публикуйте
порт наружу. Проверка выполнена компиляцией, не на реальном ТВ или DLNA-клиенте.

Номер текущего канала встроенного ТВ-тюнера запрашивается у webOS и
обновляется при событиях и периодически (до 5 секунд). Если телевизор не
сообщает номер, отображается «--». Каналы внешней HDMI-приставки телевизор,
как правило, не передаёт через этот API. Проверено сборкой, работа с
конкретным телевизором требует проверки на устройстве.

## Графики валют

На экране «Курсы» нажмите строку валюты; на графике доступны периоды 6
календарных месяцев и 1 год. Данные графика — официальные дневные курсы ЦБ РФ
(рублей за единицу валюты, с учётом номинала); они отличаются от текущих
индикативных значений MOEX на основном экране. Точки объединяются в 48
временных интервалов; минимум и максимум относятся к отображённым точкам, а не
обязательно ко всем ежедневным значениям. Нужны Wi-Fi и синхронизация NTP.
Данные ЦБ загружаются по HTTPS без проверки сертификата, как погода и MOEX;
используйте доверенную сеть. Проверено сборкой, не проверено на физической CYD.

Кнопка «Источник» отправляет webOS запрос запуска меню входов
`com.webos.app.inputpicker`; если телевизор его отклонит, пробуется
`com.webos.app.inputmgr`. После открытия меню выбирайте вход кнопками навигации
и OK на CYD. При отказе телевизора строка состояния покажет ошибку, подробности
можно посмотреть в Serial Monitor на 115200 бод. Изменение собрано, но не
проверено с реальным телевизором.

## Главный экран

На карточке первого города отображаются температура, описание, ощущаемая
температура, скорость ветра, влажность и давление в гПа. Отсутствующие данные
обозначены `--`; нужен действующий API-ключ OpenWeather. В календарь можно
попасть прокруткой главного экрана вниз. Длинное описание погоды прокручивается.
Символы, отсутствующие в шрифте экрана, заменяются на `?` при отображении;
исходные имена файлов и данные не изменяются. Проверено сборкой, проверка на
физическом устройстве необходима.

## Подсветка и избранные телеканалы

Подсветка GPIO21 удерживается выключенной во время инициализации дисплея и
первой отрисовки, затем включается с сохранённой яркостью (не раньше 750 мс
от запуска прошивки). При калибровке она включается после отрисовки метки,
чтобы подсказка оставалась видимой. Прошивка не управляет GPIO до своего
запуска: краткую вспышку на этапе сброса/загрузчика при некоторых ревизиях
платы может потребоваться устранять аппаратно.

На экране ТВ добавлены кнопки СТС (канал 13), ТНТ (19), НТВ (4) и ОРТ (9).
Передаётся команда webOS `tv/openChannel` с номером из списка встроенного
тюнера. Работу с внешней приставкой через HDMI эта команда не обеспечивает;
номера должны совпадать с настроенными в телевизоре. Поддержка этой команды
зависит от версии webOS. Исправления проверены сборкой, на плате и телевизоре
не тестировались.

## RGB-индикация будильника

При срабатывании будильника штатный RGB-светодиод мигает разными цветами,
независимо от настройки звука. При нажатии «Остановить» или автоматическом
завершении сигнала через минуту светодиод гаснет. Таймер светодиод не включает.
Используется типовая распиновка ESP32-2432S028R: R GPIO4, G GPIO16, B GPIO17,
активный уровень LOW; на других ревизиях её следует проверить. Если основной
цикл занят передачей файла SD, обработка остановки будильника может задержаться,
хотя мигание выполняется в отдельной задаче. Проверено сборкой, не на плате.

## Обновление прошивки через веб-интерфейс

Веб-OTA **без пароля**, отдельно от пароля файлового менеджера: любой клиент
локальной сети может загрузить новую прошивку. Нет шифрования или проверки
цифровой подписи. Используйте только изолированную доверенную сеть и не
пробрасывайте порт 80 в интернет. Случайный токен формы защищает только от
некоторых случайных межсайтовых запросов и не является авторизацией.

### Первая установка — по USB

Предыдущая схема `huge_app.csv` содержит только один раздел приложения и не
подходит для OTA. Теперь используется `min_spiffs.csv` для 4 МБ флеш-памяти:
два слота приложения примерно по 1,875 МиБ. Один раз запишите **по USB** новую
таблицу разделов и прошивку:

```sh
pio run -e cyd-ili9341 -t upload
```

Не используйте OTA или запись только `firmware.bin` для первого перехода:
таблица разделов должна быть записана по USB. Сделайте резервную копию важных
настроек. Проект не использует SPIFFS, однако старые данные в нём при смене
разметки могут стать недоступны. NVS в этих двух схемах расположен по прежнему
адресу, но полное стирание памяти удалит настройки. SD-карта не форматируется.

### Следующие обновления

1. Подключите CYD и компьютер к одной доверенной сети. Узнайте IP CYD на экране
   «Настройки».
2. Соберите новую прошивку командой `pio run -e cyd-ili9341`.
   Файл: `.pio/build/cyd-ili9341/firmware.bin`.
3. Откройте `http://IP-CYD/update` или нажмите «Обновить прошивку» в веб-менеджере
   SD. Страница `/update` доступна и без SD-карты. Она не требует пароля даже
   если файловый менеджер защищён паролем.
4. Выберите именно `firmware.bin` этой модели и нажмите «Обновить прошивку».
   Дождитесь сообщения об успешной загрузке и перезагрузки. Не отключайте
   питание и не используйте файловый менеджер, будильник или DLNA во время
   обновления. Большая загрузка временно блокирует экран и обработку таймера.

При ошибке записи или проверке ESP32 не должен переключаться на незавершённый
образ; подробности выводятся в Serial Monitor (115200). Нельзя менять таблицу
разделов через веб-OTA. Размер прошивки ограничен размером одного слота; сборка
PlatformIO проверяет его. OTA позволяет устанавливать только совместимые образы,
но не гарантирует защиту от злонамеренной или неправильной прошивки.

Проект собран, но загрузка и восстановление после ошибки на физической плате
не проверялись. Конфигурационный файл и прошивка могут содержать сетевые пароли.
