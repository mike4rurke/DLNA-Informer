# MultiInformer CYD + yoRadio

Реализация для ESP32-2432S028R (дисплей ILI9341 320×240) с шестью экранами
и управлением отдельным приёмником
[yoRadio_spdif](https://github.com/romekb/yoRadio_spdif). Проект создан
по мотивам [MultiInformer](https://github.com/altJSV/multiinformer),
но не является построчным портом исходной программы.

## Возможности

- NTP, календарь и погода OpenWeather для двух городов; местное время каждого
  города рассчитывается по UTC-смещению из ответа OpenWeather. Погода
  показывается красивыми иконками: солнце, луна, переменная облачность,
  облака, дождь, снег, гроза и туман (по коду иконки OpenWeather).
- Будильник по дням недели с сохранением в NVS, таймер и визуальное оповещение.
  Для звука нужен динамик на штатном выходе CYD (усилитель на GPIO 26).
- При срабатывании будильник отправляет yoRadio команду старта. Таймер не
  управляет радио и не сохраняет отсчёт при отключении питания.
- Пульт yoRadio: предыдущая/следующая станция, старт/стоп, громкость, данные
  о станции и треке по WebSocket. Используются `/?start=1`, `/?toggle=1`,
  `/?prev=1`, `/?next=1`, `/?vol=N`, `/?play=N`, `/?mode=0/1` и `/ws`
  из указанного форка.
- Экран «Радио»: переключатель Радио/SD и список станций или SD-файлов.
  Списки читаются с приёмника: `/data/playlist.csv` (WEB) и
  `/data/playlistsd.csv` (SD, формат `Название<TAB>URL<TAB>0`). Тап по строке
  включает станцию командой `play=N`. Обновление — каждые 5 минут и по кнопке.
- Экран «Настройки»: яркость подсветки, звук CYD, IP и RSSI Wi-Fi, обновление
  данных, сброс калибровки тача и файловый менеджер SD-карты (список файлов
  с размерами, только чтение). SD делит шину VSPI с тачем: на время чтения
  шина переключается и возвращается обратно. Если карта не видится — нужна
  FAT32 (exFAT не поддерживается), монтирование повторяется на 4/2/1 МГц.
- Курсы валют остались: экран «Курсы» показывает индикативные курсы MOEX
  (USD/RUB, EUR/RUB, CNY/RUB, GBP/RUB, обновление каждые 30 минут).
  Если сеть или источник недоступны, вместо вымышленных значений
  отображается сообщение об ошибке.

## Телевизор LG (NetCast)

Экран «ТВ» управляет телевизорами LG LB-серии (например 42LB65) по Wi-Fi:
протокол ROAP, порт 8080, команды `HandleKeyInput`. Питание, громкость,
каналы, крестовина с OK, назад/домой/выход, источник. Ввода цифр нет.

Сопряжение (один раз): укажите IP телевизора, прошейте, на экране ТВ
нажмите «Сопряжение» — телевизор покажет 6-значный ключ. Впишите его
в конфигуратор и прошейте ещё раз. Ключ постоянный и хранится в прошивке,
сессия кэшируется в NVS и молча обновляется. Кнопка питания только
выключает ТВ — включить можно лишь пультом или кнопкой на корпусе.
Прошивка говорит с ТВ по ROAP, а для старых моделей автоматически
переключается на HDCP. Если код не появляется: телевизор должен быть
включён и в той же сети без изоляции клиентов; на экране устройства
виден HTTP-код ответа телевизора.

## Время без Gyver

Библиотеки GyverNTP и GyverTimer не используются и в зависимостях их нет.
Вместо них — только стандартные средства Arduino-ESP32 и FreeRTOS:

- `configTime()` + `time()` из `<time.h>` для NTP-синхронизации;
- `millis()` для тика LVGL, опроса экрана раз в секунду, таймера и будильника;
- `vTaskDelay()` и отдельная задача FreeRTOS для сети (погода, MOEX, yoRadio);
- `Preferences` (NVS) для хранения настроек будильника и калибровки тача.

## Сборка и прошивка

1. Установите [PlatformIO IDE](https://platformio.org/install/ide?install=vscode).
2. Откройте папку `firmware` как проект PlatformIO.
3. Задайте в `include/config.h` Wi-Fi 2.4 ГГц, ключ OpenWeather, города и
   IP/порт вашего yoRadio. Значения в этом файле по умолчанию пустые.
4. Подключите CYD USB-кабелем с передачей данных и выберите его COM-порт.
5. Соберите и прошейте окружение `cyd-ili9341`:

   ```sh
   pio run -e cyd-ili9341 -t upload
   ```

   При необходимости добавьте `--upload-port COM3` или `/dev/ttyUSB0`.
   `uploadfs` не требуется. Готовый бинарный файл находится в
   `.pio/build/cyd-ili9341/firmware.bin`.
6. При первом включении нажмите две жёлтые метки для калибровки тача. Чтобы
   повторить калибровку, удерживайте BOOT при перезагрузке платы.

Архив, сформированный веб-конфигуратором, содержит эти же исходники с вашим
`config.h`. Сам архив не является готовым бинарным файлом прошивки.

## Дисплей

Только ILI9341, портрет 240×320 (`ILI9341_2_DRIVER`, поворот 0). Типовая распиновка
CYD: TFT MOSI 13, MISO 12, SCK 14, CS 15, DC 2, подсветка 21;
XPT2046 MOSI 32, MISO 39, SCK 25, CS 33, IRQ 36.
Экран и тач используют разные SPI-шины.

Погода и MOEX используют HTTPS с `setInsecure()`: шифрование включено, но
сертификат сервера не проверяется. Используйте доверенную сеть. Команды
yoRadio отправляются по HTTP и WebSocket без шифрования. Не публикуйте
`include/config.h` и собранный бинарник, если они содержат пароли или ключи.

Шрифты сгенерированы из DejaVu Sans; условия находятся в
`docs/DEJAVU-LICENSE.txt`.

Протокол управления и формат WebSocket сверены с исходниками
[yoRadio_spdif, commit b96a01d](https://github.com/romekb/yoRadio_spdif/tree/b96a01d).
В других версиях форка совместимость необходимо проверить отдельно.
